# Frontend — DataInova Connect

Aplicação React construida com Vite, TypeScript, TailwindCSS e Framer Motion.

Como rodar

1. Instalar dependências: `npm install`
2. Rodar em dev: `npm run dev`
3. Build: `npm run build`

Estrutura
- `src/` — componentes, pages, hooks, services (API)
- `styles.css` — entrada do Tailwind
- `tsconfig.json` — configuração TypeScript

Boas práticas
- Manter regras de negócio no backend
- Usar hooks para lógica reutilizável
- Testar componentes com testing-library + vitest (opcional)
